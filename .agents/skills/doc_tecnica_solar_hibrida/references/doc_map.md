# Mapa de documentacion tecnica solar hibrida

## Fuentes principales

- `00_Data/Enunciado_practica.pdf`: enunciado y condicionantes de la practica.
- `00_Data/Teoria_Energia_solar_termica.pdf`: base docente de energia solar termica.
- `00_Data/John A. Duffie, William A. Beckman-Solar Engineering of Thermal Processes.pdf`: referencia tecnica de procesos solares termicos.
- `00_Data/GTEST_IDAE_2022.pdf`: guia tecnica solar termica de referencia.
- `00_Data/GSTI.pdf`: guia o documentacion tecnica de instalaciones solares termicas.
- `00_Data/NRCanada-Solar_Water_Heating_Project_Analysis.pdf`: criterios de analisis de proyectos de calentamiento solar de agua.
- `00_Data/DccHE.pdf` y `00_Data/DA_DB-HE-1_Calculo_de_parametros_caracteristicos_de_la_envolvente.pdf`: soporte CTE/HE cuando afecte a demanda o justificacion energetica.
- `00_Data/Manual_de_Instalaciones_Receptoras_Gas_Natural.pdf`: criterios de instalacion receptora de gas natural.
- `00_Data/datos_GN.md`: datos normalizados de potencia y PCS para respaldo de gas natural.
- `00_Data/Normativa_Gas_Natural/`: UNE 60670 y RD 919/2006 para gas natural.
- `00_Data/Catalogos_comerciales/Captadores/`: catalogos de captadores solares.
- `00_Data/Catalogos_comerciales/Interacumuladores_ACS_bivalentes/`: catalogos de acumulacion e interacumuladores bivalentes.
- `00_Data/Manual_Criterios_de_Instalacion_Colectores_Solares-Baxi.pdf`: criterios de instalacion de captadores solares.
- `00_Data/Manual_instalacion_soportes_cubierta_solar_plana-Baxi.pdf`: soportes y montaje en cubierta plana.
- `Calculos/`: herramientas y hojas de calculo disponibles.
- `00_Instalacion_hibrida/` y `00_Plano/`: planos y artefactos CAD del sistema.
- `Practica_Solar-LaTeX/plantilla.tex`: estructura editorial final.
- `Practica_Solar-LaTeX/links.md`: referencias tecnicas ya documentadas.

## Criterio de consulta

- Usar `datos_grupo_G1-1.md` para responder con datos del proyecto ya normalizados.
- Usar `formulario.md` para formulas, simbolos y criterios base.
- Usar `00_Data/Normativa_Gas_Natural/` para seguridad, instalacion receptora, ventilacion, evacuacion y cumplimiento de gas natural.
- Usar catalogos comerciales para seleccion de equipos y justificar parametros de captadores, interacumuladores, soportes y componentes.
- Usar `Practica_Solar-LaTeX/plantilla.tex` solo para encaje editorial, no como fuente tecnica primaria.

## Referencias cruzadas

- Agente investigador: `.agents/agents/solar-termica-researcher.md`, para reunir evidencia y resolver trazabilidad entre fuentes.
- Skill tecnica: `.agents/skills/doc_tecnica_solar_hibrida/`, para documentar criterios, fuentes y calculos del sistema.
